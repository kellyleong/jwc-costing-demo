# JWC Costing Demo

Standalone interactive prototype for JWC Costing Search F0 + S1–S3.

## Local development

```powershell
pnpm install
pnpm dev
```

## Production build

```powershell
pnpm build
```

The `main` branch deploys to [kellyleong.github.io/jwc-costing-demo](https://kellyleong.github.io/jwc-costing-demo/).
